要件定義書 v3（拡張版）
プロダクト名：OrbitX
0. プロダクト定義（最重要・一行定義）

OrbitXとは、過去の自分のX投稿データを構造単位で分解・再利用し、
外部トレンドコンテンツを自動取得・提案し、
「再現性のある投稿」を半自動で量産できる、X運用特化ツールである。

感覚運用 → 構造運用

単発バズ → 再現バズ

思考 → 選択

手動発見 → 自動提案

1. 背景・課題（確定）

X運用は「センス」「気分」「記憶」に依存しがち

過去に伸びた投稿があっても、なぜ伸びたか／どう再利用すべきかが整理されない

同文再投稿・構文流用は有効だが、

手作業だとミスる

ルールが曖昧だと事故る

既存ツールは

分析止まり

自動化しすぎ

日本語運用・構文再現に弱い

6.4 AI投稿作成フロー（新規・拡張版）
【フロー1：カテゴリー選択型生成】

1. 「AIで投稿作成」ボタンクリック

2. カテゴリータブから目的のカテゴリーを選択
   （例：記事紹介、速報、公式情報引用、プレゼント企画）

3. 選択したカテゴリーの型テンプレート6種類を表示

4. ユーザーが型を選択（または「ランダム」で6種類すべて生成）

5. 選択した型の構造を完全コピーして、6パターンの投稿文を生成

6. ユーザーが1つを選択・編集して投稿

【フロー2：外部コンテンツ連動型生成】

1. 外部コンテンツ提案リストから記事を選択
   （Qiita / Zenn / Xトレンドから取得した記事）

2. 記事のタイトル・概要・URLを取得

3. カテゴリーを自動判定（記事紹介、速報など）

4. 該当カテゴリーの型テンプレート6種類から最適な型を自動選択

5. 記事情報を型テンプレートに当てはめて6パターン生成

6. ユーザーが1つを選択・編集して投稿

【フロー3：他人のバズ投稿参考型生成（手動入力）】

1. 「他人のバズ投稿を参考にする」画面を開く

2. 投稿URLまたは投稿IDを入力（または投稿本文をコピー&ペースト）

3. AIが投稿の構造を抽出・分析

4. その構造をベースに、自分のコンテンツに適用可能な6パターンを生成

5. 海外のバズ投稿も同様に手動入力可能

6. 生成された6パターンから選択

7. ユーザーが「この型を固定化する」か「一時的な使用」かを明示的に選択

8. 固定化した場合、該当カテゴリーの型テンプレートに追加（最大6種類まで）

6.5 型テンプレート生成ロジック（詳細）

【型の選定基準】

1. impression順で上位から選定

2. 構造の多様性を確保（同じ構造パターンは1つまで）

3. カテゴリーとの適合度をAIが判定

4. ユーザーが手動で型を追加・削除・置き換え可能

【型の固定化ルール】

固定化された型：カテゴリーのデフォルト型として永続保存

一時的な型：そのセッションのみ使用、次回は再選定

ユーザーが「この型を今後も使う」を選択すると固定化

【型の更新タイミング】

CSV再インポート時：全カテゴリーの型を再選定（固定化された型は除外）

手動更新：ユーザーが「型を更新」ボタンをクリック

自動提案：新しいバズ投稿が一定数蓄積されたら「型更新の提案」を表示

6.6 口調抽出・管理機能（新規）

【口調抽出（CSVインポート時）】

CSVインポート時に、全投稿をAIが分析

投稿の文体・語尾・表現パターンから口調を抽出

抽出プロセス：

1. 全投稿のテキストをAIに送信

2. AIが以下の観点で分析：
  ・語尾パターン（です・ます調、だ・である調、カジュアル調など）
  ・文体の特徴（短い文、長い文、箇条書きなど）
  ・表現の傾向（専門用語多め、カジュアル、フォーマルなど）
  ・感情表現の強さ（テンション高め、落ち着いた、など）
  ・よく使う言葉・フレーズ
  ・句読点の使い方
  ・改行の頻度

3. 分析結果から口調プロファイルを生成

4. 類似する口調パターンをグループ化

5. 各グループに名前を自動付与（例：「カジュアル調」「フォーマル調」「テンション高め」など）

6. 抽出結果を口調プロファイルとしてDBに保存

7. ユーザーが口調管理画面で確認・編集可能

【口調の登録・管理】

ユーザーが手動で口調を登録可能

口調の種類例：

・カジュアル（「〜だよ」「〜なの」など）

・フォーマル（「〜です」「〜ます」など）

・テンション高め（「〜！」「〜！！」など）

・落ち着いた（「〜ですね」「〜です」など）

・専門的（専門用語を多用）

・親しみやすい（「〜だね」「〜だよ」など）

各口調には説明文を付与可能

口調は複数登録可能（用途に応じて使い分け）

【口調の適用】

AI投稿作成時に、口調を使用するかチェックボックスで選択

選択した口調を反映して投稿文を生成

適用方法：

1. 型テンプレートの構造は完全に維持

2. 各文の語尾を選択した口調に変換
   （例：「です・ます調」→「だ・である調」に変換）

3. 表現を口調に合わせて調整
   （例：カジュアル調なら「〜だよ」「〜なの」などに変換）

4. 感情表現の強さを口調に合わせて調整
   （例：テンション高めなら「！」を追加）

5. よく使う言葉・フレーズを口調に合わせて置き換え

6. 6パターンすべてに同じ口調を適用

6.7 絵文字管理機能（新規）

【絵文字の登録・管理】

ユーザーがよく使う絵文字を登録可能

複数の絵文字を登録可能（絵文字セットとして管理）

絵文字の登録方法：

・絵文字ピッカーから選択

・直接入力（コピー&ペースト）

・よく使う絵文字の組み合わせを登録（例：「😊✨💪」）

各絵文字セットに名前を付与可能（例：「テンション高め」「感謝」「応援」など）

【絵文字の適用】

AI投稿作成時に、絵文字を使用するかチェックボックスで選択

選択した絵文字セットを投稿文に自動挿入

適用方法：

1. 型テンプレートの構造は完全に維持

2. 絵文字の挿入位置をAIが自動判定：
  ・文末に自動追加（最も一般的）
  ・文の区切りに追加（長文の場合）
  ・強調したい部分に追加（感情表現の強い部分）

3. 絵文字セットから適切な絵文字を選択
   （例：感謝の文脈なら「🙏」「ありがとう」など）

4. 投稿文の内容に合わせて絵文字を調整
   （例：技術記事なら「💻」「⚡」など）

5. 6パターンすべてに同じ絵文字セットを適用

6. 絵文字の数を適切に調整（多すぎないように）

7. カテゴリー・ジャンル分類（拡張版）
7.1 カテゴリー管理システム

【カテゴリーの定義】

カテゴリーとは、投稿の「用途・目的」を表す分類単位

例：記事紹介、速報、公式情報引用、プレゼント企画、ノウハウ、自動化、マインド、失敗談、考察、質問、議論、告知、etc.

【カテゴリーの生成方法】

初期カテゴリー：AIがCSVデータを分析し、投稿パターンから自動抽出

・対象投稿：いいね数50-200の投稿を対象

・カテゴリー数：10-20個を自動生成

・分類基準：投稿の用途・形式・構造パターンからAIが判定

追加カテゴリー：ユーザーが自由に作成・追加可能

編集：カテゴリー名の変更、削除、統合が可能

【カテゴリーとジャンルの関係】

ジャンル：投稿の「テーマ・内容領域」（例：技術、ビジネス、ライフスタイル）

カテゴリー：投稿の「形式・用途」（例：記事紹介、速報、ノウハウ）

1つの投稿は「ジャンル × カテゴリー」の組み合わせで分類される

7.2 カテゴリー別型テンプレート管理

【型テンプレートとは】

各カテゴリーごとに、過去のバズ投稿から抽出した「構造パターン」を保存

1カテゴリーあたり最大6種類の型を保持

型はCSVから成績順（impression順）で自動選定されるが、ユーザーが手動で変更可能

【型テンプレートの選定ロジック】

1. カテゴリーに該当する投稿をCSVから抽出

2. impression順にソート

3. 構造が重複しないように、多様性を保ちながら上位6件を選定

4. 各型の構造を完全に抽出・保存

【型テンプレートの固定化・変更】

固定化：この型を今後も使い続ける（デフォルト型として設定）

変更：新しいバズ投稿から型を再選定

ユーザーはUI上で「固定する」「変更する」を選択可能

認証：OAuth 2.0（投稿用のみ）

【Qiita API】

エンドポイント：https://qiita.com/api/v2

認証：アクセストークン（個人用アクセストークン）

レート制限：60リクエスト/時間（認証あり）

主要エンドポイント：

・GET /api/v2/items（記事一覧取得）

・GET /api/v2/tags/{tag_name}/items（タグ別記事）

・GET /api/v2/items?query=stocks:>10（ストック数でフィルタ）

【Zenn API】

エンドポイント：https://zenn.dev/api

認証：不要（公開API）

レート制限：明示なし（適切な間隔で取得）

主要エンドポイント：

・GET /api/articles（記事一覧）

・GET /api/articles?order=liked_count（いいね順）

・GET /api/articles?order=latest（最新順）

X API v2 Trends API（利用可能な場合）
